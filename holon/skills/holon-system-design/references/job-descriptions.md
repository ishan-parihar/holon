# Tailoring a job description

The JD is injected into every brief the employee receives, so write it for the employee:

```markdown
## Purpose
<what this employee is for, in this department, in one paragraph>

## Responsibilities
- <the outcomes it owns, tied to the department's task classes>

## Works in
- <systems, repos, paths, tools>

## Never
- <hard limits: paths, external effects, decisions reserved for others>

## Judged on
- verified results, first-pass rate, rework, cost; <department-specific KPIs>
```

Keep it under 300 words. Change it through a department review, not ad hoc.
